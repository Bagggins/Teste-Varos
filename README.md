# 🚀 Projeto Teste para Varos

O objetivo é recriar o layout e funcionalidades descritos no figma, adicionando algumas melhorias visuais.

---

## 🧩 Tecnologias Utilizadas

- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Shadcn/UI](https://ui.shadcn.com/) (para componentes de interface)
- [Prisma](https://www.prisma.io/) (para requisições com banco de dados)
- [Supabase](https://supabase.com/) (para banco de dados)

---

## ⚙️ Como Rodar o Projeto

```bash
# Instalar dependências
pnpm install

# Rodar o servidor de desenvolvimento
pnpm dev

# Compilar para produção
pnpm run build

# Iniciar em modo produção
pnpm start
```
